# TUI 快捷键

本文汇总 Sprout 全屏 TUI 的键盘与鼠标操作

## 快捷键一览

| 按键 / 操作 | 场景 | 作用 | 备注 |
| --- | --- | --- | --- |
| Enter | 输入框 | 发送内容 | 首尾空白去掉，全空白不发送；发送后清空输入框 |
| Ctrl+J | 输入框 | 换行 | 与 Shift+Enter 等价；Enter 不再换行 |
| Shift+Enter | 输入框 | 换行 | 同上 |
| Ctrl+C | 空闲 | 退出 TUI | — |
| Ctrl+C | 生成中 | 取消当前轮次 | 不退出；活动行右侧显示「Ctrl+C 取消」 |
| Ctrl+D | 任意 | 退出 TUI | 生成中亦直接退出，善后由 Shutdown 处理 |
| PgUp / PgDn | 对话区 | 上翻 / 下翻一页 | 任意时刻可用 |
| Ctrl+↑ / Ctrl+↓ | 对话区 | 上 / 下滚动一行 | 任意时刻可用 |
| Ctrl+Home / Ctrl+End | 对话区 | 跳到最前 / 最后 | 任意时刻可用 |
| ↑ / ↓ / Home / End | 对话区 | 同 Ctrl+方向键与 Home/End | **仅当输入框为空**；有内容时留给输入框移光标 |
| End | 对话区 | 滚到底部并恢复自动跟随 | 须输入框为空；与滚到底部效果相同 |
| 鼠标左键拖动 | 对话区 | 选中并复制 | 松开自动复制；拖到上下边缘自动滚动；需开启 `/mouse` |
| 鼠标左键拖动 | 输入框 | 选中并复制 | 松开自动复制；输入框为空（只有占位提示）时不选中；需开启 `/mouse` |
