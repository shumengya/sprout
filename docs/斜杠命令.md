# TUI 斜杠命令

在 TUI 输入框里发送以 `/` 开头的文本时，Sprout 会先看**第一个词**是不是下方列出的本地命令

## 补全

输入框以 `/` 开头时，输入框上方列出匹配的命令（按前缀匹配，带参数说明和用途），不必记全名：

- `Tab` 把选中项填进输入框；命令带参数时会补上空格，接着列出参数候选。
- `↑` `↓`（或 `Ctrl+P` / `Ctrl+N`）循环选择，`Esc` 关闭；同样的输入不再弹出，继续打字会重新出现。
- `Enter`：只输入了一部分（如 `/eff`）就执行选中的命令；输入已经是完整命令（如 `/model`、`/effort high`）就照原样执行；用 `↑` `↓` 选过就执行选中项。
- 参数补全：`/effort ` 列出当前模型的档位并标出当前档位；`/model ` 按包含匹配列出模型（输 `/model opus` 就能找到长引用）。
- 路径（`/etc/hosts …`）、多行输入和未知命令不会出现候选。

## 命令一览

| 命令 | 参数 | 作用 | 备注 |
| --- | --- | --- | --- |
| `/help` | 无 | 在对话区显示快捷键与命令说明 | 与空对话时新手引导中的 `/help` 指向同一帮助文本 |
| `/tools` | 无 | 显示当前模型、工作目录、数据目录，以及检测到的 `bash` / `powershell` 与不可用原因 | 信息栏不展示数据目录，在此查看 |
| `/think` | 无 | 切换**全部**思维链条目的展开 / 折叠，并同步 `showThink` 默认状态 | 单条仍可点击单独展开或收起；切换后有一条简短状态提示 |
| `/mouse` | 无 | 开关终端鼠标上报 | 默认**开启**；开启：滚轮翻页、对话区拖选复制；关闭：用终端自带选中，翻页用 PgUp/PgDn；切换时清除当前选区 |
| `/effort` | 可选 | 无参：打开思考程度档位条（← → 移动，1-9 直接选，Enter 确认，Esc 取消），下方显示该档位实际发送的参数；有参：直接切换到该档位 | 档位来自 `models.jsonc` 里当前模型的 `effort` 声明，`auto` 表示不发送思考参数；没声明的模型不能调节。生成中也能用，从下一次模型请求生效；切模型时同名档位沿用，否则退回新模型的默认档位。详见 `docs/effort.md` |
| `/model` | 可选 | 无参：打开模型选择器（↑↓ 或 Ctrl+P/N 移动，直接输入过滤，Enter 切换，Esc 取消）；有参：按 `provider/model` 引用直接切换 | 只列 `models.jsonc` 里已配置的模型；切换保留当前对话历史，清空旧模型的思维链；生成中或正在恢复/切换时拒绝 |
| `/resume` | 可选 | 无参：列出当前工作目录下最近会话；有参：异步恢复指定会话 | 选择器见下表；生成中或正在恢复时拒绝；无 `Sessions` 实现时提示不可用 |
| `/new` | 无 | 清空对话区并开始新会话 | 生成、恢复、切换模型或压缩中时拒绝；失败时保留现有内容；旧会话仍可用 `/resume` 找回 |
| `/compact` | 可选 | 把前面的**全部**对话总结成摘要，腾出上下文；`/compact 说明` 可以告诉模型摘要要特别保留什么（如 `/compact 保留所有文件路径和报错`） | 之后的请求只带摘要和新消息，对话区的内容不变、只追加一条提示。压缩期间不能发送消息或切换，Ctrl+C 取消（对话保持原样）。没有对话时提示「还没有可压缩的对话」；摘要失败时历史保持原样。和接近窗口时的自动压缩不同，这里不保留最近一轮原文。结果写进会话，`/resume` 后仍是压缩后的状态 |
| `/image` | 可选 | 无参：列待发送的图片；有参：附加一张（png / jpeg / gif / webp）到**下一条**消息；`clear` 清空全部 | 只在发送时随消息提交，发完即清空；模型没标 `vision` 时图片会被替换成占位文本并提示 |
| `/install-sprout` | 无 | 把**当前正在运行的程序**注册为全局 `sprout` 命令 | 在 `tea.Cmd` 中执行，可能改 PATH/写链接或快捷方式；`go run` 临时二进制、或无 `Installer` 时失败 |
| `/uninstall-sprout` | 无 | 卸载全局 `sprout` 注册（不删除程序文件） | 同上，异步执行并显示结果 |
| `/quit` | 无（多余词忽略） | 退出 TUI | `/exit` 等价；仅识别第一个词，故 `/quit now` 也会退出 |
| `/exit` | 无 | 同 `/quit` | 别名 |
