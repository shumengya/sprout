# 决策记录

已定的技术决策及其原因。`AGENTS.md` 的「已定技术决策」表是简表，这里补上“为什么”。理由取自各设计文档和代码注释；推翻某条决策时，在这里改写并注明日期，同时更新 `AGENTS.md`。

## 运行形态

- **单二进制、无 CGO**：目标包括 Android Termux，那里没有 CGO 工具链，也没有 systemd。所以不引入 SQLite 驱动、系统库绑定等依赖。这是硬约束。
- **Termux 产物用 `GOOS=android`**：Android 的 seccomp 禁止 `faccessat2`，`linux_arm64` 的产物会在启动时因 SIGSYS 崩溃（见 `docs/发布.md`）。
- **数据目录默认跟随二进制**（`<exeDir>/data/.sprout`），不写 `~/.sprout`：安装级配置随程序走。目录不可写时明确报错，不静默回退，避免配置被悄悄写到别处。`go run` 的二进制在临时目录，所以开发时必须显式传 `--data-dir`。
- **依赖按成本判断**：看“纯 Go 可交叉编译”和 `go.mod` 实际增加多少间接依赖，不看依赖数量本身。自写超过约两周、或涉及密码学细节的，优先引入成熟库。

## 内核与事件

- **surface 只通过事件和内核交互**（`docs/events.md`）：四种入口共用同一套会话与工具；会话落盘也订阅同一条事件流，不另开通道。
- **一轮不设步数上限**：早期默认 10 轮，真实任务里常做到一半被掐断。现在由用户取消或模型自己收尾结束，`Config.MaxSteps > 0` 时才限制。
- **中断的一轮保留在历史里**：用户已经看到的内容，模型下一轮也该看到；否则用户说“继续”时，模型既不知道上一条问的是什么，也不知道自己说到一半被打断了。半截的 tool call 参数可能不是合法 JSON，整个丢弃。
- **输出过内容后不再重试**：重试会让已显示的半截答案（CLI 里已经写进 stdout）重复输出。
- **重试不加抖动**：单个终端客户端不存在“一群客户端同时重试”的问题，固定的 1s、2s、4s… 用户看得懂。默认 7 次，上限 64 秒。
- **压缩从不静默发生**：历史被改动就一定有 `compacted` 事件和提示。摘要分层追加，不每次整份重写，避免一层层失真。
- **旧工具输出按工具类型裁剪，但仍从最旧的开始**：`read` 的内容随时能重读，只留开头；命令输出的报错和汇总在最后，留开头和结尾；子代理报告多留。不按工具排裁剪先后：最近读过的文件往往正在改，先裁它会让模型反复重读。策略带版本号落盘，旧会话按当年的版本重放。

## 会话

- **JSONL 追加写，按工作目录分组**（`docs/session-format.md`）：无 CGO、可恢复、可重放，崩溃时最多丢最后半行。
- **路径 `sessions/--<slug>--/<时间戳>_<id>.jsonl`**：2026-11-16 定为以实际实现为准，`AGENTS.md` 与 `README.md` 已同步。
- **`meta.json` 是分组索引，不是单个会话的元数据**：权威信息在各 JSONL 的 `session` 头记录里，`meta.json` 损坏可以重建。
- **恢复按运行时规则重放**，而不是存一份历史快照：同一套规则由黄金对照测试保证，旧会话按当年的规则重放。

## Provider

- **四种协议各自实现**（Chat Completions、Responses、Anthropic Messages、Gemini），只共用 HTTP / SSE 传输层：几种协议的请求、响应、流式事件结构都不同，用字符串拼接的兼容层混在一起容易出错。
- **其他供应商通过 `models.jsonc` 配置**，不写死在代码里。
- **模型参数优先级**：`models.jsonc` 手写 > models.dev 本地缓存 > 默认值（400000 / 16000）。价格只来自 models.dev，没有默认值。启动不联网，缓存由 `sprout models update` 更新。
- **思考内容原样回传**（`Message.Native`）：Anthropic 的签名思考块等协议细节，内部消息模型表达不了，就整段保存；换模型时丢弃。

## 工具

- **`bash` 与 `powershell` 都是一等公民**：是否注册由 `tools.jsonc` 开关、平台和实际检测共同决定，模型只看到当前可用的工具。Windows 只有 `System32\bash.exe`（WSL 启动器）时视为没有 bash。
- **外部工具只做参数替换再执行**，不校验参数取值，不是沙箱。
- **暂不实现权限模块**，默认完全权限。已知代价是工具子进程会继承环境变量，包括 API Key。

## 配置文件

- **JSONC**：配置文件带注释，加载前去注释，错误定位到 `文件:行:列`。
- **面板写回走 `editJSONC`**：按字节偏移拼接，保留用户的注释、BOM 和缩进；整份 `json.Marshal` 写回会丢注释。
- **技能目录追加在系统提示词末尾**，不做成模板变量：用户的 `SYSTEMPROMPT.md` 可能是旧版本，没有那个变量的模板会让技能静默失效。
- **`mcp-versions.json` 只存目标指纹的 SHA-256**：URL / args 里可能有 `${VAR}` 展开出的令牌，不能原文落盘。
- **`models.jsonc` 热加载靠定时 stat，不引入文件监听库**：每 2 秒比较一次修改时间和大小，连续两次一致才读取，避开编辑器“先清空再写”时的半截文件；开销只是一次系统调用，不值得为它加依赖。只在 TUI 里做，`run` 是单次运行，`serve` 的客户端可以自己重启进程。
