# 系统提示词（SYSTEMPROMPT.md）

发给模型的系统提示词来自数据目录下的 `SYSTEMPROMPT.md`，它是一份 Go `text/template` 模板。
文件缺失或为空时，启动会写入程序内置的模板；已有内容从不覆盖。修改后需要重启 sprout。

内置模板与仓库根目录的 `SYSTEMPROMPT.example.md` 逐字一致（测试保证）；想恢复默认，清空或删除该文件即可。

## 为什么是模板

提示词里有一部分随运行环境变化：操作系统、工作目录、日期、实际注册了哪些工具、当前模型能否识图。
写死成纯文本的话，切模型、关掉某个工具后提示词就和实际能力对不上了。
所以动态部分写成占位符和条件块，每次构造 agent（启动、`/model` 切换、`/new`、`/resume`）时按当时的环境重新渲染。

## 变量

| 写法 | 内容 |
| --- | --- |
| `{{.OS}}` | 操作系统名称，如 `Windows`、`Linux`、`macOS` |
| `{{.Cwd}}` | 启动时的工作目录 |
| `{{.Date}}` | 当前日期，`2026-01-02` 格式 |
| `{{.Now}}` | 当前时间，可格式化：`{{.Now.Format "15:04"}}` |
| `{{.Tools}}` | 实际可用的工具名列表；`{{join .Tools "、"}}` 拼成一行 |
| `{{.Vision}}` | 当前模型能否直接看到用户附带的图片 |

## 条件

```text
{{if .Has "bash"}}只有注册了 bash 时才输出这段{{end}}
{{if not .Tools}}没有任何工具{{else}}有工具{{end}}
{{if .Vision}}模型支持识图{{end}}
{{if and (.Has "bash") (.Has "powershell")}}两个 shell 都在{{end}}
```

可用 `and`、`or`、`not`、`eq`、`len` 组合。`.Has` 判断的是**最终注册**的工具：
`tools.jsonc` 里没启用、或启用了但本机没有对应 shell 的工具都不算。

## 注释与空白

- `{{/* ... */}}` 是注释，不会发给模型。内置模板开头那段使用说明就是注释。
- `{{-` 去掉左侧空白和换行，`-}}` 去掉右侧的。条件块单独占一行时，用它们避免产生多余空行。

## 出错处理

模板语法错误、变量名写错（如 `{{.Workdir}}`）、函数不存在，启动时直接报错并指出文件路径，不会静默回退到内置模板——
否则用户会以为自己的修改已经生效。为了在启动时就发现这类错误，加载后会用“无工具 / 全部工具 × 识图 / 不识图”
四组环境试渲染一遍。

## AGENTS.md：用户与项目说明

`SYSTEMPROMPT.md` 管的是提示词的骨架；想给 agent 加规矩（回复语言、项目约定、禁止的操作），写 `AGENTS.md` 更合适，不必改模板。

读取以下位置的 `AGENTS.md`，按从宽到窄的顺序追加在渲染后的系统提示词末尾（「## 用户与项目说明」一节）：

1. 数据目录的 `AGENTS.md`：全局说明，适用于所有工作目录。
2. 从工作目录的最上级（盘符根 / `/`）到工作目录本身，每一级目录里的 `AGENTS.md`：项目说明，越靠近工作目录越具体。

每份用 `<instructions scope="全局|项目" path="文件路径">…</instructions>` 包起来，模型能分清来源和作用范围；提示词里说明了冲突时以更具体的为准、用户在对话里直接说的话优先。

- 文件缺失、为空或只有空白时跳过，不会自动生成。
- 读不了（权限不足、是目录）不阻止启动，只在界面提示一次；这些文件不一定归你管理。
- 单份超过 32 KB 的部分截掉并注明，避免误放的大文件每次请求都占满上下文。
- 启动时读一次，修改后需要重启；`/model`、`/new`、`/resume` 沿用启动时读到的内容。
- 追加位置固定在末尾，不是模板变量：这样自写或旧版的 `SYSTEMPROMPT.md` 也不会让 `AGENTS.md` 悄悄失效。
- 已加载的文件记录在日志里（`logs/sprout-YYYYMMDD.log`，「已加载 AGENTS.md」）。

## 不在这个文件里的部分

以下内容仍由程序生成，不受 `SYSTEMPROMPT.md` 控制：

- 上下文压缩后追加在系统提示词末尾的「之前对话的摘要」段（`internal/agent/agent.go` 的 `request`）。
- 生成摘要时使用的专用系统提示词（`internal/agent/compact.go` 的 `summarySystemPrompt`）。
- 每个工具自己的描述和参数：在 `tools.jsonc` 里覆盖，见 `docs/tools.md`。
