# Sprout 2026.11.19

## 新增

- `sprout serve`：JSON-RPC 接口（stdio，一行一条消息）。对话、取消、会话管理、切换模型和思考程度都能用，协议见 `docs/rpc.md`。
- 子代理：`agent` 工具把一块独立的工作交给子代理，子代理只交回一份报告。内置 `general` 和 `explore` 两种，也可以在 `agents/*.md` 里自定义。
- 会话分支：`/tree` 列出会话的所有分支，可以切到任意一轮之后继续，或者回去改问那一轮，原来的对话随时能切回。
- MCP 补上 Resources、Prompts、Elicitation、Sampling 和 OAuth 登录（`sprout mcp login`）。MCP 工具返回的图片会交给模型。
- `sprout update` 现在会下载、校验并替换程序，TUI 里是 `/update`。
- 状态栏的内容和顺序可以在 `statusline.jsonc` 里自定义。
- 每轮回答下方显示耗时、首字延迟、输出速度和 token 用量。

## 改进

- `write`、`edit`、`delete` 不再和同一批的其他调用并行执行，同时改一个文件不会互相覆盖。
- 生成中提交的消息会排队发送，不会丢。
- 改了 `models.jsonc` 不用重启 TUI，会自动重新读取。
- 记住上次选的模型和思考程度。
- 旧工具输出按工具类型裁剪。`/compact -k` 只压缩最近一轮之前的对话。
- Responses 和 Gemini 的思考内容在后续轮次里会正确回传。
- 重试改为 1 秒到 64 秒的指数退避，共 7 次。

## 修复

- 首字延迟按每次模型调用分别计时，不再把一整轮算成一个首字。
- 状态栏恢复竖线分隔。

## 注意

- 旧的 `state.json` 会自动改名成 `settings.jsonc`。
- `explore` 子代理的只读只靠提示词约束，不是沙箱。
