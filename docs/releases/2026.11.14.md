# Sprout 2026.11.14

## 新增

- Agent Skills：技能登记在 `skills.jsonc`，系统提示词里只放名字和描述，正文用到时才读。`/skills` 面板开关技能，`/技能名 任务` 手动触发。
- MCP 客户端，支持 stdio 和 Streamable HTTP，配置在 `mcp.jsonc`。服务端在后台连接，不拖慢启动。`/mcp` 面板开关服务端和工具。
- `edit` 工具（按原文片段替换）和 `delete` 工具。
- `sprout update` 检查有没有新版本，并给出本平台的下载地址。
- `/compact` 手动压缩上下文。
- `sprout models update` 从 models.dev 更新本地缓存，用来补全没手写的上下文窗口、输出上限和价格。

## 改进

- 底部改成三行状态栏：路径、轮次、耗时、token、花费、上下文占用、MCP 与技能数、内存与 CPU。
- 工具卡片改成函数调用的样子，点击展开完整输出。
- 生成中按 `Esc` 取消。
- 自动压缩改为分层摘要。

## 修复

- `baseUrl` 带 `/v1` 时匹配不到 models.dev 里对应的渠道，拿到的是别的渠道的参数。
- 同名模型出现在多个渠道时，每次启动补全出来的参数可能不一样。
- 旧版 `tools.jsonc` 缺少新的内置工具时，现在会提示怎么补上。

## 注意

- MCP 目前只支持工具，Resources、Prompts、Sampling、OAuth 还没做。
- `sprout update` 只检查，不会自动替换程序。
