# Sprout 2026.11.14

第二个公开版本。上一版是最小可用闭环，这一版把「扩展能力」补齐了：MCP、Agent Skills、/mcp 与 /skills 面板、手动触发技能，外加 `sprout update` 检查新版本。

## 本版新增

### Agent Skills

技能是「目录 + 一个 `SKILL.md`」：启动时只把 `name` 与 `description` 放进系统提示词，正文在任务命中时才读进来，装二十个技能不会压满上下文。

- **注册表 `skills.jsonc`**：只有注册的技能才生效，每条包含 `path` 与 `enable`，`path` 可以指向磁盘任意位置，相对路径按数据目录解析。
- **自动注册**：扫描目录里新出现的技能自动登记进注册表；已有条目不会被覆盖，你改过的路径和开关一直有效。
- **`scanAgents` 开关**：控制是否加载 `.agents/skills`（项目里与用户主目录下的），缺省开启；关掉后那里的技能不加载，注册条目保留。
- **`/skills` 面板**：列出注册的技能与来源，`空格` / `Enter` 开关单个技能，`a` 切换 `.agents` 自动加载，`r` 重新扫描并自动注册新技能。
- **手动触发**：输入 `/技能名 任务`，例如 `/lark 整理这份会议记录`，直接把技能正文交给模型，不必等它自己判断。输入 `/` 的候选列表会列出可触发的技能；名字不是技能时整段按普通提问发送。
- 模型读到某个技能的 `SKILL.md` 时，工具卡片上会标出绿色的 `[技能] 名字`。
- 旧版的 `{"disabled": [...]}` 配置在启动时自动迁移成注册表格式。

### MCP

- 自带最小客户端（stdio + Streamable HTTP），不引官方 SDK。
- 服务端在后台连接，界面不等它：连好后自动把工具接进 agent，对话历史不丢。
- 协商版本缓存在 `mcp-versions.json`，下次启动跳过 `server/discover` 试探；缓存里只存目标指纹，不存 URL 原文中的令牌。
- **`/mcp` 面板**：列出全部服务端与展开后的工具，`空格` 开关、`→` / `←` 展开收起、`r` 重读配置并重连。开关直接写回 `mcp.jsonc` 并保留注释与排版。

### 工具

- **`edit`**：按原文片段替换，修改文件不用整份重写。
- **`delete`**：删除文件。
- 工具卡片改成函数调用形式，可点击展开完整输出。
- 生成中按 `Esc` 取消，与主流终端 agent 一致。

### 命令行

- **`sprout update`**：查询 GitHub Releases 的最新版本并与当前版本比较，不一致时打印发布页与本平台压缩包的下载地址。`--repo OWNER/NAME` 可指向 fork。只提示，不自动替换正在运行的程序。

### 界面与模型

- 底部信息栏改为三行状态栏，显示路径、轮次、耗时、token 用量、花费、上下文占用、MCP 与技能数，以及整机内存与 CPU 占用。
- `models.dev` 的本地缓存用来补全没手写的上下文窗口、输出上限与价格；`sprout models update` 更新缓存，启动时不联网。价格与花费按实际请求的缓存读写 token 统计。
- `/compact` 手动压缩上下文；自动压缩改为分层摘要，新切掉的一段追加成新的一层，按 token 目标从最旧的开始裁剪旧工具输出。

### 修复

- 用户写的 `baseUrl` 带 `/v1` 时匹配不到 `models.dev` 的渠道，会拿到同名模型在别的渠道下的参数（窗口、价格都可能不对）。现在比较前会去掉末尾的接口版本段。
- 同名模型在不同渠道出现时，回退结果随 map 遍历顺序变化，补全出来的参数每次启动可能不同。现在按渠道名排序后再建索引。
- 旧版 `tools.jsonc` 缺少内置工具条目时提示如何补上。

## 安装

见下方「下载」。首次运行会在程序所在目录的 `data/.sprout/` 生成带注释的 `models.jsonc`，填入 API Key（或设置对应环境变量，如 `DEEPSEEK_API_KEY`）后重启即可。

Windows 上双击 `sprout.exe` 进终端界面；在 TUI 里执行 `/install-sprout` 可注册成全局 `sprout` 命令（改用户 PATH），`/uninstall-sprout` 卸载。

从上一版升级：直接替换可执行文件，数据目录（配置、会话、日志）原样保留。执行 `sprout update` 可以查看有没有更新。

## 已知限制

- **没有权限模块**：默认完全权限，模型可以直接执行命令、读写文件，技能正文也等价于把仓库里的文字塞进上下文。工具子进程继承环境变量（包括 API Key）。请只在你能接受这个前提的环境里使用。
- **没有 WebUI 与 JSON-RPC**：`sprout serve` / `sprout web` 还没实现。
- **`sprout update` 只检查不下载**：它读 GitHub Releases 的最新发布并给出本平台产物的下载地址，替换程序需要手动完成。
- **MCP 只做了工具**：Resources、Prompts、Sampling、OAuth 都还没做。
- **macOS / Linux / Termux 只验证到能编译**：`bash` 探测、进程组终止、剪贴板等 Unix 路径只有单元测试，没有在真实系统上手工跑过。遇到问题请反馈。
- **OpenAI 官方服务未验证**：Chat 与 Responses 都只在 DeepSeek 上跑过真实对话；带 reasoning 的 gpt-5 / o 系列行为可能不同。
- **`models.jsonc` 不支持热加载**：改完要重启（`mcp.jsonc` 与 `skills.jsonc` 不用，面板里就能刷新）。
- **并行工具靠提示词约束**：同一批调用互相看不到结果，有依赖的命令要分回合。
- **`go test -race` 未跑**：开发机没有 CGO 工具链。
- **macOS 未签名**：首次运行需要右键打开，或 `xattr -d com.apple.quarantine sprout`。
