# Sprout 2026.11.23

## 新增

- `agent` 工具可以放到后台跑：模型在调用里加 `run_in_background: true`，主代理不用干等，子代理的报告做完自动送回。默认仍是前台。其他工具可以在 `tools.jsonc` 里用新的 `background` 字段打开。
- 生成过程中发的消息，当前这批工具跑完就交给模型，不用等整轮结束。
- `Ctrl+V` / `Alt+V` 粘贴剪贴板里的图片。Windows Terminal 会拦下 `Ctrl+V`，用 `Alt+V`。
- `sprout run` 能读 stdin，例如 `git diff | sprout run 审一下 -`。`sprout run -i` 不进全屏界面，一行一问。
- `sprout sessions clean --older-than 30d` 清理旧会话，可加 `--dry-run` 先看会删哪些。`settings.jsonc` 里设 `cleanupPeriodDays` 可以在启动时自动清理，默认不清理。

## 改进

- 大图片不再直接拒绝：长边超过 2000 像素或超过 3 MB 时自动缩小。
- 日志只保留 30 天。
- 会话名写进会话文件本身，不再维护 `meta.json`。旧版本起的名字照常显示。

## 修复

- Gemini 的输出 token 没算思考部分，花费和输出速度偏低。
- 启动时 MCP 后台连接和界面同时读写服务端列表，有数据竞争。

## 注意

- 后台任务只在当前这一轮里有效：模型答完会等它们结束，这期间界面一直是忙碌状态，但可以继续发消息。
- 已有的 `tools.jsonc` 不会被改写；`agent` 不写 `background` 时默认就能放到后台。

升级：`sprout update`，或直接替换可执行文件。
