# Sprout 2026.11.12

首个公开版本。Sprout 是 Go 写的跨平台 agent runtime：内核是一个 ReAct 循环，终端界面只是它的一个外壳。单二进制、无 CGO，Windows 优先开发，同时发布 Linux、macOS 与 Termux 版本。

这一版是**最小可用闭环**：能聊天、能调工具、能恢复会话、能换模型。权限模块、WebUI、JSON-RPC、MCP、skills 都还没做，见下方「已知限制」。

> 本包的二进制构建于加上 CI 之后的第一个通过提交。首次在 Linux / macOS 上跑测试时发现三处只在非 Windows 平台暴露的问题，已修复并进了这个包：中文直接贴着图片路径写时（`看这张图：/tmp/截图.png这张`）Unix 绝对路径会丢掉开头的斜杠，导致图片找不到；`go run` 临时目录的判断不认识 Windows 风格的反斜杠路径；命令一致性测试在 CRLF 检出下会截错函数体。
>
> **Termux 包重新编译过**：先前的 `termux_arm64` 复用了 Linux ARM64 的产物，在真机上启动即 `SIGSYS: bad system call`——Android 的 seccomp 策略禁止 `faccessat2`（syscall 439），而 `GOOS=linux` 的 Go runtime 会先试它，被拦时进程直接被杀，没有回退机会。现在改用 `GOOS=android GOARCH=arm64` 单独编译（产物不依赖 libc，`NEEDED` 为空），其它平台的包不受影响。

## 本版能力

### 内核

- ReAct 循环：模型调用 → 工具执行 → 结果回传，**轮数默认不设上限**，任务做完为止；靠用户取消或模型自己收尾结束。
- 中断保留：Ctrl+C 取消或调用失败的轮次不丢弃，已收到的正文与思维链连同中断说明留在历史里；下一轮说「继续」时模型知道自己停在哪。
- 并行工具：同一批调用并发执行（默认 4 路），历史顺序与调用顺序一致。
- 自动重试：网络失败、429、5xx、流被截断按指数退避重试，听 `Retry-After`；已经向界面输出内容后不再重试。
- 上下文管理：接近窗口时先裁剪旧工具输出，不够再把早期对话总结成摘要；服务端报超长时压缩一次再重试。
- 完整事件协议（`turn.started` / `message.delta` / `reasoning.delta` / `tool.requested` / `tool.finished` / `usage` / `retrying` / `compacted` / `interrupted` / `turn.finished` / `error`），会话可重放。

### 模型

四种协议，都可以在 `models.jsonc` 里配置多个供应商：

| 协议 | 状态 |
| --- | --- |
| OpenAI Chat Completions | 已用 DeepSeek 真实服务验证 |
| OpenAI Responses | 已用 DeepSeek 的 `/responses` 端点验证；OpenAI 官方服务未验证 |
| Anthropic Messages | 已实现并测试（含思考块签名回传） |
| Google Gemini | 已实现并测试 |

- 流式输出、思维链显示、图片输入（png / jpeg / gif / webp）。
- `/model` 运行时切换模型，保留对话历史。
- `/effort` 调节思考程度，档位由 `models.jsonc` 按模型声明。

### 工具

- `bash`：Git Bash / MSYS2 / Cygwin / 系统 bash；Windows 上只有 WSL 启动器时明确提示安装 Git for Windows。
- `powershell`：优先 pwsh 7+，回退 5.1，工具描述按 edition 区分语法。
- `read` / `write`：按行读取、原子写入。
- 外部命令工具：在 `tools.jsonc` 里把任意命令包装成工具，参数按 shell 规则加引号。
- 每个工具都要在 `tools.jsonc` 里显式 `"enable": true` 才交给模型；模型只看到当前可用的工具。
- 执行契约：独立进程、固定工作目录、默认 120 秒超时（可传 `timeout_seconds`）、输出上限 50 KB（保留头尾）、超时与取消终止整个进程树。

### 终端界面

- 全屏 TUI（Bubble Tea v2），流式输出、工具卡片（命令、退出码、耗时、输出预览）。
- Markdown 渲染：标题、列表、任务列表、引用、表格（完整边框、中文对齐）、代码块语法高亮。
- 中文按字折行并遵守避头尾规则。
- 滚动与复制：滚轮、PgUp/PgDn、Ctrl+↑↓、Ctrl+Home/End；对话区与输入框都能拖选复制（同时走 OSC 52 和系统剪贴板）。
- 斜杠命令补全（Tab）、`/help`、`/tools`、`/think`、`/mouse`、`/effort`、`/model`、`/resume`、`/new`、`/image`、`/install-sprout`、`/quit`。
- `/resume` 会话浏览器：可搜索（关键词 / `re:` 正则 / `"短语"`）、排序、重命名、删除。

### 命令行

```bash
sprout                                  # 终端界面
sprout run "看看当前目录有什么"          # 单次运行，答案写 stdout，进度写 stderr
sprout run --image shot.png "这张图里是什么"
sprout -c                               # 恢复当前目录最近的会话
sprout --effort high                    # 指定启动时的思考档位
sprout --version
```

退出码：0 成功，1 运行失败，2 用法错误，130 被 Ctrl+C 中断。

### 配置与数据

- 数据目录默认 `<程序所在目录>/data/.sprout`，跟随二进制；`--data-dir` / `SPROUT_DATA_DIR` 覆盖。
- `models.jsonc`：模型、协议、API Key 环境变量、`maxOutput`、`contextWindow`、思考档位。JSONC 支持注释，语法错误定位到 `文件:行:列`。
- `tools.jsonc`：工具开关、描述、参数 schema、外部命令定义。
- `SYSTEMPROMPT.md`：系统提示词是 `text/template` 模板，可以按读到的值改写。
- `AGENTS.md`：数据目录一份全局说明，加上工作目录到盘符根各级的项目说明，按从宽到窄追加进系统提示词。
- 会话按工作目录分组写成 JSONL，`meta.json` 是索引；恢复后接着写原文件。

## 安装

见下方「下载」。首次运行会在程序所在目录的 `data/.sprout/` 生成带注释的 `models.jsonc`，填入 API Key（或设置对应环境变量，如 `DEEPSEEK_API_KEY`）后重启即可。

Windows 上双击 `sprout.exe` 进终端界面；在 TUI 里执行 `/install-sprout` 可注册成全局 `sprout` 命令（改用户 PATH），`/uninstall-sprout` 卸载。

## 已知限制

这些是刻意留到后面的，不是遗漏：

- **没有权限模块**：默认完全权限，模型可以直接执行命令、读写文件。工具子进程会继承环境变量（包括 API Key）。请只在你能接受这个前提的环境里使用。
- **没有 WebUI 与 JSON-RPC**：`sprout serve` / `sprout web` 还没实现。
- **macOS / Linux / Termux 只验证到能编译**：`bash` 探测、进程组终止、剪贴板等 Unix 路径只有单元测试，没有在真实系统上手工跑过。遇到问题请反馈。
- **OpenAI 官方服务未验证**：Chat 与 Responses 都只在 DeepSeek 上跑过真实对话；带 reasoning 的 gpt-5 / o 系列行为可能不同。
- **配置改完要重启**：`models.jsonc` 不支持热加载。
- **并行工具靠提示词约束**：同一批调用互相看不到结果，有依赖的命令要分回合（模型不听话时会自己纠正）。
- **`go test -race` 未跑**：开发机没有 CGO 工具链。
- **macOS 未签名**：首次运行需要右键打开，或 `xattr -d com.apple.quarantine sprout`。
