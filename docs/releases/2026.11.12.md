# Sprout 2026.11.12

首个公开版本。首次运行会在程序所在目录的 `data/.sprout/` 生成 `models.jsonc`，填好 API Key 后重启即可。

- 终端界面，以及单次运行 `sprout run "..."`：答案写 stdout，进度写 stderr。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Google Gemini 四种协议，可以在 `models.jsonc` 里配置多个供应商。`/model` 运行中切换模型，`/effort` 调思考程度。
- 内置 `bash`、`powershell`、`read`、`write` 工具。`tools.jsonc` 可以把任意命令包装成工具。
- 图片输入（png / jpeg / gif / webp）。
- 会话按工作目录保存。`sprout -c` 恢复最近的会话，`/resume` 搜索、重命名、删除历史会话。
- 失败自动重试，接近上下文上限时自动压缩。按 Ctrl+C 取消的回答会留在历史里，说「继续」就能接着做。
- Markdown 渲染（表格、代码高亮），对话区和输入框都能拖选复制。

## 注意

- 没有权限模块：模型可以直接执行命令、读写文件，工具子进程会继承环境变量（包括 API Key）。
- macOS / Linux / Termux 只验证到能编译。macOS 包未签名，首次运行需要右键打开，或执行 `xattr -d com.apple.quarantine sprout`。
- Termux 包重新上传过：最早那份复用了 Linux ARM64 的产物，在真机上一启动就崩（`SIGSYS`）。如果你下载过，请重新下载。
